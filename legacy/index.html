Mengapa Memilih LPK-MI?

Instruktur Praktisi

Panduan Pendaftaran

  1. Pilih program pelatihan yang sesuai dengan kompetensi yang ingin Anda sertifikasi.
  2. Lengkapi data diri, instansi, dan kontak aktif Anda.
  3. Unggah dokumen persyaratan (KTP, Ijazah terakhir).
  4. Kirim pendaftaran. Anda akan langsung menerima Sertifikat Pelatihan LPK Simulasi secara otomatis untuk dicoba pada website LSPMI.

Note Integrasi: Sertifikat dari LPK ini dapat digunakan sebagai prasyarat wajib (dokumen bukti pelatihan) di formulir pendaftaran LSPMI Anda.

Daftar Fitur Integrasi yang Dibutuhkan dari LSPMI ke LPK

Untuk menghubungkan sistem LPK (yang sedang dibuat ini) ke sistem LSPMI Anda, berikut adalah antarmuka (API) dan data yang saling dibutuhkan:

# Fitur Integrasi Deskripsi Teknis Arah Data Status Simulasi
1 API Verifikasi Sertifikat LSPMI mengirim request HTTP GET ke LPK dengan nomor sertifikat pelatihan untuk memeriksa validitas dan mencocokkan NIK peserta. LSPMI LPK Siap Diuji
2 Sinkronisasi Skema Kompetensi LPK mengambil data daftar Skema Sertifikasi aktif dari database/API LSPMI agar pilihan program pelatihan LPK selalu selaras. LPK LSPMI Terpetakan
3 Pendaftaran Jalur Cepat (Fast-track) Setelah lulus LPK, sistem LPK mengirim data asesi secara langsung ke backend LSPMI via API POST sehingga asesi tidak perlu mengisi formulir LSP dari awal. LPK LSPMI Demo Integrasi
4 Pencocokan NIK Otomatis Validasi silang NIK untuk menghindari pemalsuan identitas atau penggunaan sertifikat milik orang lain saat mengajukan uji kompetensi. Dua Arah Siap Diuji
